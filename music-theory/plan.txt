Build a static web application (HTML, CSS, Vanilla JavaScript only — no backend) that functions as an interactive music theory visualizer based on a circular chromatic note layout.

The application must be modular, readable, and production-ready. No frameworks unless absolutely necessary. SVG should be used for graphics rendering.

1. Core Concept: Circular Chromatic Layout

Create a circle that represents the 12 semitones arranged like a clock:

Index mapping (clockwise):

0 → C (12 o'clock)
1 → C#
2 → D
3 → D#
4 → E
5 → F
6 → F#
7 → G
8 → G#
9 → A
10 → A#
11 → B

Requirements:

Render circle using SVG.

Evenly space 12 labeled nodes.

Nodes must be clickable.

Selected note becomes the “Tonic” (base note).

Rotating the tonic should behave as a geometric rotation (do NOT re-render positions — just change interval calculations).

2. Interval System (Half-Step Based Engine)

All calculations must be based on semitone distance (H = half step).

Base Interval Mapping

m2 = 1H
M2 = 2H
m3 = 3H
M3 = 4H
P4 = 5H
P5 = 7H
m6 = 8H
M6 = 9H
m7 = 10H
M7 = 11H
P8 = 12H

Augmented Intervals

Aug = Major or Perfect + 1H

Aug2 = 3H
Aug3 = 5H
Aug4 = 6H
Aug5 = 8H
Aug6 = 10H
Aug7 = 12H
Aug8 = 13H

Diminished Intervals

Dim = Minor or Perfect − 1H

Dim2 = 0H
Dim3 = 2H
Dim4 = 4H
Dim5 = 6H
Dim6 = 7H
Dim7 = 9H
Dim8 = 11H

3. Functional Harmony Lines (Toggleable)

Draw colored SVG lines between tonic and related scale degrees.

Each relationship must be toggleable via UI controls (checkbox panel).

Dominant (D) → 7H
Subdominant (SD) → 5H
Mediant (M) → 4H
Submediant (SM) → 9H
Supertonic (ST) → 2H

Major-only:
Leading Tone (LT) → 11H

Minor-only:
Subtonic → 10H

Tonic (T) → 12H (octave)

Each relationship must:

Have unique color

Be toggleable

Update dynamically when tonic changes

4. Scale Generator

Implement:

Major Scale pattern:
W W H W W W H
(2 2 1 2 2 2 1 in semitones)

Minor Scale pattern:
W H W W H W W
(2 1 2 2 1 2 2)

When a tonic is selected:

Highlight notes belonging to selected scale

Draw connections between scale degrees

Allow switching between Major and Minor

5. Interval Visualization Mode

Add a UI panel that allows:

Selecting any two notes

Displaying:

Semitone distance

Interval name

Inversion

Interval inversion rule:
Inversion = 12H − original interval

Example:
C → G = 7H (P5)
G → C (next octave) = 5H (P4)

Show both original and inverted interval.

6. Triads and Chords

Implement chord construction from tonic:

Major Triad = 0, 4, 7
Minor Triad = 0, 3, 7
Diminished Triad = 0, 3, 6
Augmented Triad = 0, 4, 8

Display:

Highlighted chord notes

Lines forming a triangle

Chord name label

Allow:

Locking chord structure

Sliding tonic (rotational transformation)

Chord updates automatically

7. Emotional Harmony Assistant

Add a section that suggests chord progressions and emotional qualities.

Examples:

Major Progressions:
I – IV – V → stable, resolved
I – V – vi – IV → emotional / pop
ii – V – I → jazzy resolution

Minor Progressions:
i – iv – v → dark, modal
i – VI – III – VII → cinematic
i – iv – VII → melancholic

When tonic changes:

Progressions update automatically

Clean dark theme

Responsive layout

Side control panel:

Scale selector (Major/Minor)

Hover tooltips explaining interval math

MIDI playback (Web Audio API)
